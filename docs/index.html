System-One Control Bench

A model guides an agent across a small grid puzzle to a goal, one move at a time, choosing each move from a list of options. A solver knows every best move, so every choice can be scored exactly. The 100 puzzles range from 1 to 20 steps, and many need a key for a locked door. The leaderboard uses compass rules (one step per move) and two conditions, map only and full context, so each player plays 200 games.

Conditions

A condition sets what the player is told. Every request has the rules, the numbered map, the agent's position, what it carries and where the key, door and goal are (map only). Four components can be added: surroundings (what is next to the agent and how far away each object is), move history (every move so far and what it did), move outcomes (each option says what it would do) and subgoal (the question names the next target).

Move rules

A move is one decision. Under the sequence rules a move is several steps chosen together, and every possible sequence is offered, including ones that walk into walls.
